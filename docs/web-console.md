# 本机 Web 控制台

控制台监听 `127.0.0.1`，访问 `task-conductor status` 返回地址的 `/admin/`。保持本机访问，不使用 LAN 地址、反向代理或公网转发。全部管理操作也可通过 [CLI](cli.md) 完成。

## 启用与连接

setup 生成独立管理员令牌，读取后粘贴到连接表单：

```bash
task-conductor console token
# macOS 复制：
task-conductor console token | pbcopy
```

自定义安装附加 `--home 绝对目录`。令牌仅保留在页面内存，退出或刷新后重新连接。

已有配置缺少 `TASK_CONDUCTOR_ADMIN_TOKEN` 时，先停服，用本地密码管理器生成独立随机令牌，加入当前 dataDir 的 `environment.json` 后启动。配置和环境文件须属于当前用户、权限为 `0600`，目录为规范绝对路径、权限为 `0700`；不接受符号链接。字段约束见 [environment.ts](../src/configuration/environment.ts)。这些文件按明文凭据保护。

## dsh 内访问

dsh Web 侧栏的“任务控制台”面板（位于“期权工作台”下方）使用同一管理员 API，提供任务、执行端与服务配置页面。插件经 dsh 宿主把同源请求转发到本机服务，不把服务端口暴露给浏览器页面；管理员令牌默认保存在本机 dsh 凭据中，刷新页面后自动连接；连接时可取消“记住令牌”，断开连接会清除已保存值。独立页面与 CLI 保持可用，服务未运行或管理员 API 未启用时，dsh 页面显示对应提示。

该页面沿用 dsh 自身的认证与传输边界。dsh 以明文 HTTP 暴露到 LAN 时，管理员令牌随页面连接传输；应将 dsh 限制在本机，或在 TLS 之后访问。

## 操作范围

| 页面 | 可用操作 |
| --- | --- |
| 任务 | 查看 DAG、运行、节点、交付和问题；修改名称与时间计划，暂停或恢复未来触发 |
| 执行端 | 查看准备状态，重新检测、升级适配器、注册或注销自定义本机 ACP |
| 设置 | 配置协调模型与密钥；在高级设置修改数据目录、端口、MCP token 变量名及执行端启停 |

任务目标、DAG 和执行指派在创建时固定；对话与问题回答通过 MCP 完成。任务更新和自定义执行端注册即时生效，服务设置在重启后生效。执行端准备与原生授权见[部署说明](deployment.md#执行端发现与准备)，注册要求见 [CLI](cli.md#自定义本机-acp-接入)。

未保存表单会保留草稿，离开前提示确认。页面失焦后自动刷新可能暂停，需要最新状态时点击“刷新”。

## 保存与重启

1. 密钥只显示设置状态；保留、替换或删除均按表单操作。先保存新密钥，再保存引用它的配置。更换模型端点时使用新的凭据引用，避免中途重启将新密钥交给旧端点。
2. 点击“预览变更”查看校验结果和受影响任务，再确认保存。修改表单或密钥后重新预览。禁用执行端会阻止后续派发，已有任务保持原指派。
3. 核查活动及待回答 Run 后点击“重启服务”，或执行 `task-conductor restart`。重启关闭 ACP 会话，可能中断待回答运行；目录切换的影响见[部署说明](deployment.md#数据目录与管理)。
4. 等待重启完成，使用返回的新地址重新连接并核对配置。期间保持当前页面；请求超时或结果提示丢失时，用 `task-conductor status` 查询当前实例。

Web 与 CLI 保存后都会使旧编辑失效；发生冲突时重新读取配置并人工核对。离线编辑须先停服。保存与校验入口见 [Settings](../src/configuration/settings.ts) 和[配置影响预览](../src/configuration/management.ts)。

## 安全

管理接口使用独立认证和浏览器来源检查。页面按纯文本展示任务及模型输出，密钥原值不回显；日志和 Agent 输出仍须按敏感内容处理。该部署以本机 OS 用户为信任范围。
